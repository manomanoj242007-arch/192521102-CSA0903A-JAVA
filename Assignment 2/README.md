# Assignment 2 – Java Programs and Outputs

Each Q1–Q7 folder contains:
- Expanded Java source code, formatted line by line.
- `output.txt` with console output from a local OpenJDK 21 execution.
- `output_screenshot.svg`, a visual console-output image.

## Run
Open a terminal in the required question folder and execute:
```bash
javac Q1.java
java Q1
```
Replace Q1 with the relevant question number. Benchmark timings depend on computer, Java version and system load; run several trials on your own system when preparing final experimental results.
