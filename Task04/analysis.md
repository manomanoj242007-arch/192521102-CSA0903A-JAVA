# Task04 – Analysis

ParkingTicket demonstrates default, overloaded, parameterized, chained and copy constructors. this() avoids repeated initialization; final fields are initialized once and invalid values are rejected. A local reference is in a stack frame while the object is on the heap. After exit processing removes all references, the ticket is eligible for garbage collection. Setter creation can temporarily create invalid objects; factories centralize validation. Creating n tickets is O(n) time and O(n) total heap space.
